Your PC, streamed to anywhere.

Solstice is a self-hosted game stream host for Moonlight. It captures your Windows desktop or a single application, encodes it in hardware, and streams it with low latency to a phone, tablet, TV, or another computer. Pairing, settings, and logs live in a web UI on your own network.

Download the latest release Read the documentation

What you get

A Windows 11 host built for Moonlight clients, with the capture, encoding, and input paths handled by the hardware that is already in your machine.

Hardware encoding

NVENC on NVIDIA, AMF on AMD, QuickSync on Intel, and Media Foundation on Qualcomm, with a software encoder as a fallback.

Desktop capture

DXGI Desktop Duplication in portable and service mode, plus Windows.Graphics.Capture in portable mode.

Virtual gamepads

Xbox 360, Xbox One, Xbox Series, DualShock 4, DualSense, Switch Pro, and Steam Controller, fixed or chosen from the client's controller.

Signed-in web UI

Pair clients, change settings, and read logs from https://localhost:47990, with an optional "remember me" session.

Keyboard, mouse, touch, pen

Injected with the Windows SendInput and pointer APIs. No extra driver is needed for those devices.

Sunshine-compatible

Existing Sunshine configuration is picked up automatically, and the client, application, and state file formats are unchanged.

Requirements

Windows 11 only. Older versions exit at startup with an explanatory message.

Host requirements
OS Windows 11 build 22000 or newer, x64 or ARM64
GPU NVIDIA NVENC, AMD VCE 1.0 or newer, Intel Skylake or newer with QuickSync, or Qualcomm with Media Foundation encoding
CPU AMD Ryzen 3 / Intel Core i3 or better
RAM 4 GB or more
Network 5 GHz 802.11ac or wired Ethernet on both host and client

4K or HDR? A modern mid-range GPU (GTX 1080 / VCE 3.1 / HD Graphics 730 or better), a Ryzen 5 or Core i5, and wired Ethernet on both ends are a better starting point. These recommendations are a work in progress — do not buy hardware based on them alone.

Install

The installer is a single executable. It registers the service, the firewall rules, and the web UI.

  1. Download the installer Grab Solstice.exe from the latest release.
  2. Run it and follow the prompts Approve the elevation prompt so Solstice can install its service and the streaming firewall rules.
  3. Open the web UI Browse to https://localhost:47990, create the first account, and pair your Moonlight client.
  4. Optionally, add a virtual gamepad driver HIDMaestro, libvirtualgamepad, or ViGEmBus. Without one, keyboard, mouse, touch, and pen input still work.

Portable mode is available too: run solstice.exe from an extracted folder and it keeps its configuration alongside the executable.

Virtual gamepads

Solstice can present the client's controller to games as a different pad. Three backends are supported, and ViGEmBus is always the fallback when the preferred one cannot create the profile.

libvirtualgamepad

A user-mode Virtual HID Framework driver bundled with the installer under drivers\vhf-gamepad. Adds Xbox One, Xbox Series, DualSense, Switch Pro, and Steam Controller profiles.

HIDMaestro

Supports every profile, including Xbox 360. Solstice drives it through a self-contained bridge under drivers\hidmaestro; install the HIDMaestro driver and it is used automatically.

ViGEmBus

The always-available fallback, covering Xbox 360 and DualShock 4. Pin any backend with the gamepad_backend configuration option.
